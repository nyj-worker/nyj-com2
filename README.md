# 남양주시 산업 구조 및 기업 생태계 심층 분석 대시보드 (nyj-com2)

경기도 남양주시 활동기업 41개월(34,219개 사) 및 전국공장등록 6개 반기 빅데이터를 입체적으로 시각화하여 양적 성장의 실체, 고용 양극화, 제조 기반 변화와 미래 4대 정책 방향을 한눈에 제시하는 인터랙티브 웹 대시보드입니다.

## ✨ 핵심 기능 및 특징

1. **3D Data Intelligence Hero Background**
   * Three.js 기반의 입체적 파티클 메쉬 및 그라디언트 비주얼 효과
2. **핵심 6대 지표 총괄 요약 (Overview Bento Grid)**
   * 활동기업 수, 국민연금 가입 종사자, 등록 공장 수, 지식기반 기업, 식료품 비중, 신설/휴폐업 배수
3. **7대 심층 영역 인터랙티브 시각화 (Chart.js & Motion)**
   * 01. 고용 변동 및 규모 구간별 기업·종사자 증감
   * 02. 업력 구조 및 단계별 생존 분석
   * 03. 핵심 5대 업종 비교 및 특화도
   * 04. 신설 및 휴폐업 동향 (활력 지수)
   * 05. 경기 5개 시군(남양주, 화성, 김포, 파주, 평택) 비교
   * 06. 공장등록 및 제조 기반 변화 (사분면 분석)
   * 07. 기업 이전 동향 및 지리적 흐름
   * 08. 4대 핵심 정책 제언
4. **플로팅 탑(Top) 버튼 & 스크롤 진행률 링**
   * 스크롤 250px 초과 시 자동 등장 (페이드/스케일 애니메이션)
   * 페이지 스크롤 위치를 실시간으로 표시하는 SVG 원형 프로그레스 링
   * 원클릭 부드러운 최상단 스무스 스크롤 복귀
5. **100% 클라이언트 사이드 정적 웹 호스팅 완벽 지원**
   * GitHub Pages, Vercel, Netlify 등 어디서나 즉시 배포 가능
